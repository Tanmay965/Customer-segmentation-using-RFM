# Customer Segmentation using RFM

## Project Overview
This project focuses on customer segmentation using RFM (Recency, Frequency, Monetary) analysis to identify distinct customer groups based on purchasing behavior. The analysis was performed using Python for data cleaning, preprocessing, and feature engineering, followed by visualization in Power BI to generate actionable business insights.

## Tools & Technologies
- Python (Pandas)
- Power BI
- RFM

## Dataset
- Online Retail / Transaction Dataset

## Workflow
1. Loaded transactional dataset using Python  
2. Cleaned data by handling missing values, removing duplicates, and filtering invalid entries  
3. Created new features such as TotalPrice  
4. Performed RFM analysis:  
   - Recency: Days since last purchase  
   - Frequency: Number of transactions  
   - Monetary: Total spending  
5. Assigned RFM scores using quartile-based segmentation  
6. Classified customers into segments (VIP, Loyal, At-Risk, Regular)  
7. Exported the final RFM table as a CSV file  
8. Imported the data into Power BI for visualization  

## Key Features
- RFM (Recency, Frequency, Monetary) Analysis  
- Customer Segmentation (VIP, Loyal, At-Risk, Regular)  
- Data Cleaning & Preprocessing  
- Data Transformation & Aggregation  
- CSV Data Export for Visualization  
- Interactive Dashboard Visualization  
- Customer Behavior & Purchase Pattern Insights  

## Outcome
Developed a structured customer segmentation model that helps identify high-value customers, at-risk customers, and loyal customers, enabling better marketing strategies and business decision-making.
